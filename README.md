# Illinois Enrollment Demographics Dashboard

Tableau project analyzing longitudinal enrollment patterns across student level, race/ethnicity, and gender using publicly available University of Illinois enrollment statistics.

## Project Overview

This project uses Tableau to explore how enrollment composition changes over time. The dashboard emphasizes both absolute enrollment and demographic share, making it possible to compare long-run trends across groups and student levels.

## Analytical Questions

- How has enrollment changed over time across demographic groups?
- How do undergraduate enrollment shares differ by race and ethnicity?
- Which groups move up or down in rank over time?
- How do gender trends differ across student populations?

## Tableau Techniques

- Longitudinal trend visualization
- Percentage-of-total calculations
- Rank-order charts
- Stacked area charts
- Fixed-level calculations
- Demographic segmentation

## Data Source

The analysis uses publicly available University of Illinois enrollment statistics. UIUC institutional research resources publish historical enrollment data by dimensions such as student level, gender, race/ethnicity, and residency.

Relevant public sources include:

- UIUC Data & Analytics for Institutional Research (DAIR) — Student Enrollment
- UIUC historical institutional enrollment reports

Because the workbook was created from a locally downloaded copy of the data, the original local file path may appear inside the Tableau workbook metadata.

## Repository Contents

The `Atlas intern/` directory contains the Tableau workbooks and source spreadsheets used during development. `IL.twb` is the primary Illinois enrollment workbook.

## Portfolio Takeaway

This project demonstrates the use of Tableau for longitudinal demographic analysis, calculated fields, ranking, percentage-based comparison, and communication of institutional enrollment trends.

## Note

This repository is presented as a portfolio version of an analysis built from public institutional enrollment data; it does not rely on confidential individual-level student records.
